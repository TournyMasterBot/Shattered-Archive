# Required Software
* [nvm](https://github.com/coreybutler/nvm-windows)
* NodeJS v20 (nvm install 20)
* [Visual Studio Code](https://code.visualstudio.com/Download)

# Pre-Quickstart
* `npm install` the package root
* `npm install` './src/game-client
* `npm install` './src/game-server
* `npm install` './src/web-client'
* `npm install` './src/web-server'

# Quickstart
> Execute 'Pre-Quickstart' once
* Open the project code workspace (`ShatteredArchive.code-workspace`)
* `npm run start` in terminal
```
Game Client: `http://localhost:8480`
Web Client: `http://localhosst:8080`
```

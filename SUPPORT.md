# Support

## Community Support

ShatteredArchive is a community-driven, fan-operated project.

Support is provided on a best-effort basis through the following channels:

- GitHub Issues for bug reports and feature requests
- Project documentation at https://shatteredarchive.com/

There are no guaranteed response times.

---

## Reporting Bugs

If you encounter a bug:

1. Search existing GitHub Issues to see if it has already been reported
2. If not, open a new issue with:
   - Steps to reproduce
   - Expected vs actual behavior
   - Relevant logs or screenshots

---

## Security Issues

Please do **not** report security vulnerabilities via public issues.

Refer to [SECURITY.md](./SECURITY.md) for responsible disclosure instructions.
